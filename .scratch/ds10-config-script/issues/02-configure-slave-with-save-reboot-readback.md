# 02 — 配置从机(含 CFG_SAVE 保存 / 重启 / 重连 / 读回校验)

**What to build:** `--role slave` 一条命令把一台 DS10 配成从机,并建立整套"保存→重启→重连→读回"机制。脚本进入 AT 会话后依次下发 `CFG_NEW → CFG_ROLE=1 → CFG_UART=115200,8,0,1 → CFG_SLE=1,1`(可选功率 / STATUS)`→ CFG_SAVE`;保存触发重启后,脚本关闭串口、在带重试的重连窗口内等待、重新打开并重进 AT,读回角色与工作模式并与期望值比对,最终打印"✅ 配置已生效"或列出所有不符项。从机不配置任何通道路由。

这一票交付的重连 / 读回机制供 ticket 03 复用。

**Blocked by:** 01 — 读取 DS10 设备信息 + AT 会话与假 DS10 测试骨架

- [ ] 无线 SLE 预设显式设为 Polar 码 + 均衡档(frameType=1, tier=1),不依赖 `CFG_NEW` 草稿默认值
